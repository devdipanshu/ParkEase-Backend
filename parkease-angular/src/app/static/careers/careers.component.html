Careers at ParkEase

Why ParkEase?

  • Work on a real-world product used by actual drivers and lot owners

Backend Engineer — Spring Boot

Full-time · Remote

Design and build microservices for booking, payment, and analytics. Own the full lifecycle — schema design, API contracts, testing, and deployment.

Stack: Java 17, Spring Boot 3, MySQL, Redis, Docker

Frontend Engineer — Angular

Full-time · Remote

Build pixel-perfect, accessible UI components for our driver and manager dashboards. Collaborate closely with design and backend to ship features end to end.

Stack: Angular 18+, TypeScript, Angular Material, RxJS

DevOps / Platform Engineer

Part-time · Remote

Manage our Docker Compose setup, CI/CD pipelines, and cloud deployments. Help us move toward Kubernetes as we scale.

Stack: Docker, GitHub Actions, AWS / GCP
